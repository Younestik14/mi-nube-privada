# REBT Suite — Rediseño Diseñador Pro

Esta versión incorpora una segunda capa de diseño eléctrico sobre la aplicación existente.

## Cambios
- Nueva interfaz de Diseñador Pro.
- Dashboard de proyecto con KPIs.
- Gestión y edición de circuitos.
- Auto-dimensionado preliminar de sección y PIA.
- Inspector REBT con errores, avisos y OK.
- Reparto simple de cargas L1/L2/L3.
- Unifilar SVG automático.
- Presupuesto preliminar por circuitos.
- Importación/exportación de proyectos JSON.
- Arquitectura separada en `v6_engine.py` y `v6_ui.py`.

## Importante
El auto-dimensionado y el inspector son una capa preliminar. Para uso profesional deben verificarse método de instalación, temperatura, agrupamiento, tipo de cable, caída admisible aplicable, cortocircuito, selectividad, diferenciales y tablas REBT/UNE correspondientes.
